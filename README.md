## 启动

```bash
npm install
npm run dev
```

- 前台：http://localhost:5173
- 后台：http://localhost:5173/admin
- API：http://localhost:3007/api/health

本地默认管理员：

```text
账号：admin
密码：password
```

生产环境请设置 `ADMIN_JWT_SECRET`，并替换默认管理员密码。当前后端使用 MySQL 持久化。

管理员登录后进入“账号与权限”，负责账号授权和网站设置。请创建独立编辑者并分配文字、图片、音乐或视频权限后维护歌手内容。已有管理员的 `*` 权限会自动收窄，不修改原有密码或内容。

管理员也可进入“网站设置”（`/admin/settings`），填写公共页脚的版权说明、ICP备案号与链接、公安备案号与链接，以及关于页面的标题和 Markdown 正文。留空的备案项不会显示；访客从任意前台页面的页脚进入 `/about`。设置独立保存在 MySQL 中，仅管理员可修改，保存操作会记录到操作日志。
关于正文支持标题、表格、分隔线、列表、引用、代码、图片、网页和 `mailto:` 邮箱链接，并可在后台展开“预览关于内容”查看排版。“关于页面二维码”支持选择或拖入最大 5MB 的图片，上传后保留原始尺寸并转为 PNG；“微博链接”填写完整 HTTP / HTTPS 地址。点击“保存网站设置”后，二维码和“访问微博”入口显示在关于正文下方，二维码可点击查看原图；清空对应设置即可隐藏。
公共页脚采用站点品牌、栏目导航、关于简介和联系信息的分栏布局；站点名称、简介、关于摘要、联系邮箱与说明也在“网站设置”中维护。默认介绍和 example.com 邮箱为演示内容，可按需替换。
“网站设置”还支持浏览器标题、favicon、顶部名称与副标题、顶部和页脚标识及印章文字、页脚小字。网站图片支持选择文件或拖入 PNG / JPG / WEBP / GIF / AVIF（最大 5MB），也可填写站内或 HTTP / HTTPS 图片地址；已有 ICO 图标可通过地址使用。上传的 favicon 自动生成透明留边的 64 × 64 PNG，顶部和页脚图片按比例完整显示。上传完成后点击“保存网站设置”统一生效；上传期间禁止保存，清除 favicon 恢复默认图标。顶部名称留空沿用歌手名称，副标题和页脚小字留空隐藏。网站图片仅管理员可上传。

默认本地数据库配置：

```dotenv
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=root
MYSQL_DATABASE=wiki
ADMIN_PASSWORD=password
ADMIN_JWT_SECRET=artist
AUDIT_RETENTION_DAYS=15
```

服务启动时会自动创建数据库、内容表、用户表、版本表、编辑锁表和审计日志表。管理员进入后台的“操作日志”可以查看账号、内容和上传操作；日志默认保留 15 天，服务启动时和运行期间每日自动清理。

## 留言板

- 前台入口：顶部导航“留言”（`/guestbook`），与影卷、视频同排。留言列表在上、Waline 编辑器在下，沿用本站纸色与红色强调；不显示登录、昵称或回复。左侧提供 Waline 基础图片表情和图片上传（仍支持 Markdown 排版），右侧显示字数、“预览”和提交。上传图标也支持自己的图片表情（含 GIF），预览可查看排版；删除编辑器中的图片标记即可移除附件。最多 4 个附件，单个不超过 2MB，正文最多 5000 字。
- 提交成功后浮出“留言已提交，审核通过后将会展示”，4 秒后自动消失，并切换到“我的留言”；失败保留草稿。匿名凭证保存在当前浏览器的网站数据中，刷新后仍可查看本人记录；更换浏览器或清除网站数据后无法找回该身份。共用同一浏览器配置的用户也共用这一身份。未提交的图片仅在当前页面暂存，刷新后需重新选择。
- 接入方式为 **Waline 官方客户端 3.16.1 + 本站 API 适配层**：编辑器与表情选择器使用官方组件，列表、举报、后台审核和数据库继续使用本站实现，不单独部署 Waline Server、不迁移历史记录。详情见 [Waline 接入说明](docs/waline-integration.md)。
- 管理员进入“留言管理”（`/admin/guestbook`）查看待审核、已公开、精选、待处理举报、未通过 / 已撤下记录；可审核、撤下、设为精选或取消精选。前台保留精选标识与筛选，按当前选定的热度或最新排序。撤下自动取消精选。删除需二次确认，会永久移除文字、附件、点赞和举报，本人预览也不可再读取。审核人、审核时间及举报原因统计仅供后台查看，普通编辑者没有管理权限。
- 留言列表左侧提供筛选，不显示留言总数，右侧提供“热度 / 最新”（默认最新）：热度按点赞数降序，同赞数按发布时间降序；最新严格按发布时间降序。切换或重复点击任一排序都会重新获取数据并回到第一页，因此前台不再另设刷新按钮。没有登录门槛，也没有评论回复功能。
- 已公开留言支持匿名点赞/取消点赞及举报。同一浏览器身份对同一条留言只计一次赞或举报，并保存自己的互动状态；举报从固定原因中选择，不新增未经审核的公开文字。后台可忽略举报，或选择“举报成立并撤下”。举报不会自动使留言下架，已处理的同一身份举报不会反复重开。互动按 IP 每小时最多 120 次；匿名去重不等于实名防刷，清除浏览器身份后可形成新身份。
- 留言和附件独立存储在 MySQL，服务重启时自动创建所需表。未审核的文字与附件仅本人和管理员可读取；上传附件不进入公共 `/uploads`。Markdown 原始 HTML 不执行，外链图片不直接显示，请使用图片上传。按 IP 每小时最多提交 12 次，包含失败尝试；公开和本人列表每页 10 条。
- 安全检查记录见 [留言板安全检查](docs/guestbook-security.md)。`npm run test:guestbook-db -w apps/server` 会创建独立临时数据库，验证迁移、提交、图片权限、审核、精选、并发点赞去重、排序、举报处理及完整删除后清理，不修改项目数据库；需要本地 MySQL 的建库权限。

## 批量上传图片和音频

- **图片**：编辑者进入“图集管理 → 新增图集 / 批量上传图片”，或编辑已有图集，多选或拖入图片，填写图集信息后保存。每个图集最多 100 张，单张最大 25MB；图片素材页也有图集入口。
- **音频**：编辑者进入“歌曲管理 → 批量上传歌曲”，一次导入最多 100 个音频，单个最大 25MB。自动识别歌名、演唱者、专辑和发行时间，可修改、试听或移除，点击“保存全部歌曲”后生效；每个音频生成独立歌曲和历史版本。同名封面和歌词可同时选择，例如 `棠梨煎雪.mp3`、`棠梨煎雪.jpg`、`棠梨煎雪.lrc`；匹配依据是原始文件名（不含扩展名，忽略大小写），不是音频标签中的歌名。也可先上传音频，再补充同名附件。封面可预览，歌词可查看和修改；歌词支持 UTF-8 LRC / TXT，最大 1MB，须含时间标签。
- 上传列表显示每个文件的状态与进度。部分文件失败不影响后续上传；取消会保留已经导入的内容，可重试未完成文件。保存歌曲失败时仅重试未保存项，无需重新上传。
- 图集图片需 `image.write`，音频和歌词需 `music.write`，歌曲封面另需 `image.song.write` 权限；只读账号不显示批量入口。已有歌曲、视频及网站标识的单张封面上传流程保持不变。

## 服务器备份

支持在测试服务器每天北京时间 19:00 完整备份 MySQL 和上传文件，并通过 SSH 发送至 `.env.ssh` 指定的备份服务器。接收端只保留最新一份完整备份：传输并校验成功后清理旧备份，失败保留上一份可用备份和本地待重试文件。安装、状态检查及恢复范围见[备份说明](docs/backup.md)。
