# 图集、作品与视频资料

## 图集

后台「图集管理」把一次发布的多张照片作为一组内容保存。填写分类、标题、说明、作者类型与署名、拍摄或发布时间、地点，再批量选择或拖入图片。每组最多 100 张，每张最多 25MB；支持 JPG、PNG、WEBP、GIF、AVIF。

每张照片可填写关键词和描述、调整顺序，并可设为图集封面。移除当前封面后，第一张剩余照片自动成为封面。上传失败不会清空已成功上传的图片；取消仅停止后续上传，已添加的图片仍可随图集保存。

粉丝 ID 为选填；「前台展示粉丝 ID」默认关闭。关闭时后端不向公开内容接口发送该字段，后台仍可搜索。已有单张照片自动兼容显示为单图图集，旧版本恢复也保留兼容。

## 作品

「作品」支持按歌名、演唱者（包括合唱歌手）、专辑名和歌词搜索，多个搜索词用空格分隔。后台「演唱者」可填写多个名字，例如 Critty / Aki阿杰。

按后台填写的专辑名称自动归组；未填写名称的歌曲显示在「未归入专辑」。专辑封面使用该专辑第一张已填写的歌曲封面。可以浏览专辑、播放整张专辑；无音源的歌曲保留在资料列表中，但不会进入播放队列。
「全部歌曲」工具栏下方显示专辑名称与歌曲数量，点击即可筛选这张专辑的歌曲；专辑筛选可与关键词搜索组合，点击「全部专辑」清除专辑限制。原有「按专辑浏览」封面卡片入口继续保留。

歌曲列表显示小封面。后台歌曲编辑中填写完整「MV 链接」后，前台按钮会在新标签页打开该链接；留空则置灰。

## 视频

后台「视频管理」支持现场（活动）、歌曲 MV、vlog、直播切片、其他五类。「其他」可用于手动收录歌词排版等二创视频。

可填写作者 / 摄影 / 剪辑署名、时间、地点、关键词、简介和 Markdown 补充正文。前台分类筛选和搜索涵盖这些字段，点击封面或「查看详情」可查看视频和完整说明。视频播放沿用项目现有的 B 站链接方式。

三个栏目的前后台搜索均支持不区分英文字母大小写的部分匹配；用空格分隔的多个词需要全部命中。编辑权限沿用原来的图片、音乐、视频权限设置。
