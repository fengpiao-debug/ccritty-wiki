# 留言板安全检查

检查日期：2026-10-24。范围：匿名留言、Markdown 渲染、图片/表情上传、本人预览、管理员审核/精选/删除及相关生产依赖。

## 结果与修复

- 原有 Markdown 关闭了原始 HTML，测试中未复现脚本执行。本次增加 DOMPurify 标签与属性白名单，作为 Markdown 渲染后的第二道防线；Waline 草稿预览、本人记录、公开列表和管理员管理页共用同一安全渲染函数。没有将“人工审核”当成 XSS 防护。
- 白名单仅保留正文排版、链接和预置本地表情，不允许脚本、事件属性、样式、iframe、表单、SVG、MathML、对象嵌入等活动内容。留言链接仅保留 HTTP、HTTPS、mailto 或站内相对链接；外链使用 `noopener noreferrer`。正文外链图片不加载，图片统一走审核附件。
- 图片先检查扩展名、MIME、魔数，再由 Sharp 解码并重新编码为 WebP；SVG、伪装 HTML、超限图片和过多附件均被拒绝。保留 2MB 单文件、4 个附件、1600 万像素和 100 帧限制。附件响应固定 WebP 类型，并设置 `nosniff`、沙箱 CSP、禁止缓存及同站资源策略。
- 未审核、未通过或撤下的附件只有原浏览器匿名凭证持有者及管理员可取；附件不进入公开静态目录。匿名凭证使用 32 字节随机数，数据库只保存其 SHA-256 摘要。昵称不采集、不返回，公共及本人列表也不再暴露管理员审核账号。
- 审核、精选和删除均验证 JWT、当前用户及管理员角色；匿名访客、留言本人和普通编辑者不能调用管理操作。客户端传入审核状态、精选标志和归属标志不能改变新留言的待审核状态。
- 精选更新在数据库内限定 `status = approved`，避免把待审核留言直接设为精选；撤下同时取消精选。删除使用事务和行锁，将留言、附件一并移除，删除后公共、本人和后台附件接口都不可读取。
- SQL 参数均绑定；排序与筛选 SQL 片段由服务端固定枚举生成。分页与留言字数受限。现有提交频率限制按 IP 每小时最多 12 次，失败尝试也计数。
- 生产依赖审计发现相关组件的已知拒绝服务/底层依赖风险，已更新 `markdown-it` 至 15.0.3、`multer` 至 2.5.0、`sharp` 至 0.35.5、`body-parser` 至 2.4.0；新增 DOMPurify 3.4.17。复查 `npm audit --omit=dev --registry=https://registry.npmjs.org` 返回 0 项已知漏洞。原镜像不支持 audit 接口，因此使用 npm 官方注册表复查。

## Waline 接入补充

- 使用官方 `@waline/client` 3.16.1，构建适配仅作用于该包的 API 和 Markdown 导入，不修改依赖文件或全局网络函数。昵称/登录/回复不进入本站提交接口，原有 MySQL、管理员权限、审核与附件隔离不变。
- 官方原生预览的 HTML 解析被本站安全渲染器替换，不能因更换编辑器而恢复原始 HTML 执行。新图片表情仅允许固定本地路径，不接受用户指定外链；正文存储短代码。
- 自选图片先在页面内暂存，提交时再发给原审核接口。预览仅允许本次编辑器实际创建的 Blob URL；未知 Blob、data URL、SVG 与外链图片被阻止。成功提交和组件卸载会回收临时 URL；失败保留文件以便重试。
- 客户端与表情素材固定版本，生产依赖审计再次返回 0 项已知漏洞。客户端使用 MIT 许可，表情素材单独保留 GPL-3.0-or-later 许可及来源说明。

## 验证

- 自动测试覆盖 14 类恶意 Markdown，包括 script、事件属性、混合大小写/实体编码的危险协议、data URL、SVG、MathML、iframe、外链图片及代码块。四个展示入口均检查实际 DOM 不包含可执行节点/属性；另模拟 Markdown 层返回危险 HTML，验证第二道白名单仍能清洗。正常加粗、表格、列表、代码和安全链接保持可用。
- API 回归覆盖未授权审核/精选/删除、客户端伪造状态、仅已审核内容能精选、撤下取消精选、删除后附件不可访问、SVG/伪装文件/超限上传、匿名归属隔离和频率限制。
- 真实 MySQL 集成验证旧表自动迁移、匿名提交与图片持久化、JWT 管理权限、精选/取消精选、审核公开、撤下、重新连接读取和事务删除无孤立附件。使用独立临时库并在结束后清理。
- 新增互动检查：仅公开留言可点赞/举报，状态在事务中锁定验证；点赞/举报以“留言 + 匿名身份摘要”唯一键去重，重复请求及并发请求不重复累计。举报原因使用固定枚举，不采集公开回复；举报详情不返回前台，处理接口限定管理员，举报数量不触发自动隐藏。删除同步移除互动记录。
- 真实 MySQL 新增验证：同一身份并发点赞去重、取消点赞幂等、不同身份状态隔离、热度/最新排序差异、举报去重与忽略/撤下、删除后无互动孤立记录。接口回归包含互动参数校验、私有留言不可互动、非管理员不可处理举报及跨匿名凭证的 IP 限流。
- 新增真实 Waline 组件回归：匿名提交、图片表情插入/预览/短代码保存、原生图片上传只在提交时发送、失败保留草稿、无登录/回复、4 秒提示、共享安全渲染与危险 HTML。适配层覆盖附件限额、移除/重试/回收、失效 Blob 和禁用接口。
- `npm test`：75 项后端测试、239 项前端测试通过。

## 边界

本次是代码检查、依赖审计和针对性回归，并非完整渗透测试，不能保证未来或所有环境中绝无漏洞。匿名“本人”指持有同一浏览器凭证的人：共用浏览器、凭证泄露或站点其他页面出现同源 XSS 都可能影响该身份。现有后台登录令牌也使用浏览器存储，因此本站其他渲染入口仍需保持安全。

提交限流为单进程内存计数，重启会重置，多实例部署需另配共享限流；生产代理需要正确配置真实客户端 IP。上线应使用 HTTPS、独立强管理员密码与生产 JWT 密钥，并持续更新依赖。删除是永久删除，后台操作前已有二次确认；如需恢复，应使用站点数据库备份。

点赞/举报另设每 IP 每小时 120 次的单进程限流。同一浏览器匿名身份唯一不代表同一自然人唯一，清除凭证或更换设备可建立新身份；此方案不能完全防止分布式刷赞，举报仍由管理员核查。
