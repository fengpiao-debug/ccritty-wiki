# 权限说明

权限格式为 `领域.动作`：

- `text.read/write`
- `image.read/write`
- `music.read/write`
- `video.read/write`
- `content.publish`
- `content.rollback`
- `user.manage`

## 职责分离

- 管理员（`role: admin`）：仅拥有 `user.manage`，负责创建、删除编辑者账号、重置其密码和分配权限。不参与内容查看、编辑、上传、发布或回滚。
- 编辑者（`role: editor`）：仅拥有管理员分配的内容权限，不能管理用户，不能赋予自己更高权限。
- 不再接受 `*` 通配权限。服务启动时将历史管理员记录收窄为 `user.manage`；运行时仍根据角色计算有效权限，不信任历史权限字段。
- 编辑权限必须同时包含同领域的查看权限。创建和更新账号均校验权限白名单，禁止赋予编辑者 `user.manage`。
- 管理员账号受保护，不能通过普通编辑者管理接口删除或修改。

## 校验边界

后端每次请求读取当前账号权限。授权变更或账号删除对现有令牌即时生效，不以 JWT 内的旧权限作为依据。
登录恢复使用 `/api/auth/me`，前端不再信任浏览器缓存的权限信息。
前端隐藏菜单和按钮仅为交互优化；后端分别验证内容读取、修改、历史版本、回滚和资源上传权限。
回滚同时要求对应内容的编辑权限及 `content.rollback`，并校验编辑锁。历史预览同时要求对应内容查看权限及 `content.rollback`。

## 管理界面

`/admin/users` 为管理员首页，提供搜索、角色过滤、分页和中文授权矩阵。
编辑者首页进入首个可访问栏目；无权限账号进入待授权页面。手动输入不属于自身权限的路由也不会显示相应管理界面。
