# 更新记录

### 2026-10-04

- 动态和活动新增关键词搜索与时间排序，点击同一个排序按钮即可在“最新在前”和“最早在前”之间切换，文字和箭头显示当前顺序；默认按时间从新到旧展示，日期待定的内容始终排在最后。
- 动态和活动支持在后台添加、修改和清空标签，前台可点击标签筛选，与关键词搜索、时间排序组合使用，也可跳转查看另一栏目中同标签的内容。
- 修复刷新时短暂显示“锦书”、示例动态及默认网站信息的问题；等待资料时展示加载状态，加载失败可重试，首页“近讯”按最新时间排列。
- 管理员可在“网站设置”修改浏览器标题、上传替换 favicon，保存后立即生效，清除后恢复默认图标。
- 顶部和页脚支持分别替换标识图片、印章文字及小字；顶部站点名称、副标题与页脚名称、简介均可自行维护，也可一键将顶部标识复制到页脚。
- 页脚“探索档案”补齐“视频作品”入口，可直接进入视频栏目。

### 2026-10-03

- 歌曲目录和播放器播放列表新增“+”按钮，可将选中歌曲设为下一首播放，当前播放进度保持不变。
- 前台作品、影卷、视频及后台内容、账号搜索新增关键词高亮，支持多个关键词和清空搜索后恢复原样。
- 歌词搜索结果显示命中位置附近的歌词片段，并高亮关键词，自动隐藏歌词时间标记。
- 活动时间树改为中央主线、活动卡片左右交错排列，海报与活动信息一起展示；手机端自动切换为单列时间线。
- 动态时间树同步采用中央主线和左右交错卡片，保留按日期排序、配图与来源链接，手机端自动切换为单列。

### 2026-10-02

- 影卷升级为图集：支持四种分类、批量上传、封面选择、照片排序、作者、时间和地点，并可为每张照片填写关键词与说明；旧照片和历史版本继续可用。
- 图集、作品和视频均支持多字段搜索；作品可按合唱歌手、专辑或歌词检索，支持专辑浏览与整张播放，显示歌曲小封面，并可关联 MV。
- 视频新增现场、歌曲 MV、vlog、直播切片和其他分类，可填写作者、关键词、时间、地点及补充正文。
- 动态改为时间线，活动显示上传的图片；首页简介标题可编辑，统计入口可跳转到对应栏目。
- 播放器可收起到左下角，只保留切歌、播放和展开按钮，继续保持播放进度。
- 新增公共页脚与关于页面，管理员可自行维护介绍、联系信息和备案信息。
- 使用人物头像作为站点图标，并修复独立封面编辑权限的后台入口。
- 修复恢复旧版本后仍残留新字段、视频日期无法回显的问题；解析视频信息时等待处理完成后再保存。
