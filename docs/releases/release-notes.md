# 更新记录

### 2026-10-03

- 活动时间树改为中央主线、活动卡片左右交错排列，海报与活动信息一起展示；手机端自动切换为单列时间线。

### 2026-10-02

- 影卷升级为图集：支持四种分类、批量上传、封面选择、照片排序、作者、时间和地点，并可为每张照片填写关键词与说明；旧照片和历史版本继续可用。
- 图集、作品和视频均支持多字段搜索；作品可按合唱歌手、专辑或歌词检索，支持专辑浏览与整张播放，显示歌曲小封面，并可关联 MV。
- 视频新增现场、歌曲 MV、vlog、直播切片和其他分类，可填写作者、关键词、时间、地点及补充正文。
- 动态改为时间线，活动显示上传的图片；首页简介标题可编辑，统计入口可跳转到对应栏目。
- 播放器可收起到左下角，只保留切歌、播放和展开按钮，继续保持播放进度。
- 新增公共页脚与关于页面，管理员可自行维护介绍、联系信息和备案信息。
- 使用人物头像作为站点图标，并修复独立封面编辑权限的后台入口。
- 修复恢复旧版本后仍残留新字段、视频日期无法回显的问题；解析视频信息时等待处理完成后再保存。
